# Nordic Spade: downloads

Nordic Spade is a private AI assistant that runs on your own computer, with a companion app for Android.
This page only holds the finished app files. The source code is kept elsewhere.

**[Open the releases](../../releases)**

- **PC (Linux):** releases named `pc-<number>`. A new computer needs `Nordic-Spade-installer.sh`. A computer that already
  has Nordic Spade updates itself from Settings → App → Check for updates.
- **Android phone:** releases named `phone-<number>`, file `NordicSpade.apk`. Once installed, the app updates itself
  from Settings → Updates.

Every file has a `.sha256` fingerprint next to it. The update buttons check it before installing anything.
